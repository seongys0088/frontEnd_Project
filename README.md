# 🎮 SENTENCE MASTER - ARCADE EDITION

무작위로 섞인 영어 단어 카드를 드래그 앤 드롭하여 한글 문장에 맞는 올바른 순서로 재배치하는 영어 문장 완성 게임입니다.

## 📌 프로젝트 개요
* **개발자**: 성윤수
* **주요 기술**: HTML5, CSS3, JavaScript, jQuery, JSON

## 🚀 핵심 구현 사항 (필수 요구사항)
1. **데이터 독립성**: 게임 문제는 외부 `data.json` 파일에서 관리되며, JSON 파일 교체만으로 문제 변경이 가능합니다.
2. **단어 카드 시스템**: 영어 문장의 단어들을 빈칸 기준으로 분리하여 카드화하고, 무작위로 섞어서 나열합니다.
3. **정교한 위치 제어**: HTML5 Drag & Drop API를 활용하여 카드의 위치를 변경하며, 마우스 좌표 계산을 통해 카드 사이사이에 자유롭게 끼워 넣을 수 있습니다.
4. **한글 문장 표시**: 상단에 문제 가이드가 되는 한글 문장을 그대로 표시합니다.
5. **정답 검증**: 단어 카드가 올바른 문장으로 완성되면 해당 문제를 완료하고 다음 단계로 진행합니다.

## 💎 추가 구현 기능 (옵션 및 차별점)
1. **사용자 관리 및 보안**: 플레이어 이름과 비밀번호를 입력받아 개인별 데이터를 관리하는 로그인 시스템을 구현했습니다.
2. **콤보 및 스코어 시스템**: 연속 정답 시 'COMBO STREAK' 가중치 점수가 부여되며, 실시간으로 총점과 퀘스트 진행 상황을 표시합니다.
3. **게임 이력 관리 (LocalStorage)**: 브라우저 저장소를 활용하여 사용자별 최고 점수와 최근 게임 로그(날짜, 점수)를 영구 보존합니다.
4. **세련된 아케이드 UI**: 네온 핑크와 블루를 메인 컬러로 사용하고, CRT 주사선 효과 및 애니메이션을 적용하여 몰입감 있는 디자인을 완성했습니다.
5. **타이머 기능**: 문제별 제한 시간을 도입하여 긴장감 있는 게임 플레이를 유도합니다.

## 📂 파일 구성
* `index.html`: 게임의 전체적인 구조와 레이아웃 정의
* `style.css`: 아케이드 테마 디자인, 네온 효과 및 애니메이션 스타일링
* `script.js`: 게임 로직, 드래그&드롭, LocalStorage 데이터 제어
* `data.json`: 한글/영어 문장, 점수, 시간 등 게임 데이터 세트
* `jquery-3.7.1.js`: 효율적인 DOM 조작을 위한 라이브러리

## 🛠 실행 방법
1. 프로젝트 폴더 내의 모든 파일을 동일한 경로에 유지합니다.
2. 브라우저 보안 정책(CORS)으로 인해 반드시 **VS Code의 Live Server** 확장 프로그램을 사용하여 실행하거나, **Github Pages**에 호스팅된 URL을 통해 접속해야 정상적으로 작동합니다.
